# UniLink collaboration additions

Implemented: cross-campus professional discovery; student, alumni, faculty, recruiter, and founder profile categories; industry, role, education, company, location, and career-goal filters; deterministic matching based on skills, interests, industry, mentoring intent, portfolio activity, and shared institution; visibility and mentor opt-in; verified-user discovery; block enforcement; connection requests and recipient approval; mentorship requests and status workflow; jobs, internships, referrals, scholarships, startup and volunteer opportunity posts with expressions of interest; alumni networking events with registration; team/project listings, hackathon team applications, owner approvals and capacity checks, shared team tasks and status updates, basic adoption statistics, and existing portfolio/GitHub links.

Entry point: **Alumni Network** in the sidebar (the existing `collaborate` route is retained). Server module: `server/collaboration.js`. New tables are created at startup and existing collaboration profile tables receive additive, idempotent column migrations. `database/professional_network.sql` documents the additional tables. No external AI service is used; matching is deterministic and explainable, not generative AI.

Security: server checks session authentication, team membership for tasks, team owner for approvals, and blocks for discovery/applications. These are not a substitute for an independent security audit. The opportunity board records expressions of interest; it is not an external ATS and does not submit applications to third-party hiring systems. A production release should still receive a full UI typecheck/build, stronger moderation, pagination, end-to-end tests, and a security review.

Run: Node >=22.13; `npm install`, `npm run dev`; then visit Collaborate. Run `npm run typecheck`, `npm run lint`, `npm run check` before release. Existing admin bootstrap and authentication flows were not changed in this patch.
